# Slisk

## Xbox 360 Wireless → PS4

Det här repot ska innehålla vårt projekt för Xbox 360 Wireless Receiver (USB 045E:0719) direkt till PS4 GoldHEN som spelare 2 utan mellanliggande dator eller Control4Free.

**Status:** USB och Xbox→PS4-knappmappning har testats på konsolen. Virtuell spelare 2 fungerar ännu inte. v0.7.5 kraschade spelet och v0.7.9 låste konsolen; installera inte dessa. Senaste v0.8.0-paketet är ett offline-test av säkerhetsfixar, inte en spelbar release.

Se [utvecklingsstatus och kända fel](docs/STATUS.md). När en ny seriös konsoltestkandidat finns ska både källkod/version i GitHub och direktnedladdning i ChatGPT erbjudas.
